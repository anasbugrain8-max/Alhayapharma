# بوت التحصيل — شركة الحياة فارما

بوت Telegram لمتابعة تحصيل المديونيات من العملاء بواسطة مندوبي الشركة، مع نظام صلاحيات
(مدير 👑 / مساعد 👨‍💼 / مندوب 👤).

## الملفات
- `bot.py` — الكود الكامل (قاعدة بيانات SQLite + توليد PDF + منطق البوت) في ملف واحد.
- `requirements.txt` — المكتبات المطلوبة.
- `fonts/NotoNaskhArabic-Regular.ttf` — **يجب إضافته يدوياً** (راجع `fonts/README.txt`) حتى تظهر
  النصوص العربية بشكل صحيح داخل ملفات الـ PDF.
- `logo.png` (اختياري) — شعار الشركة، إن وُجد سيظهر أعلى تقارير الـ PDF.

## سجل التحديثات (v1.1)
- ✅ تصحيح أعطال تصدير PDF: الآن يظهر تنبيه واضح إذا كان ملف الخط العربي غير موجود بدل تعطل الزر بصمت.
- ✅ إدخال قيمة السداد والهدف الشهري أصبح عبر لوحة أرقام تفاعلية (بدل الكتابة اليدوية).
- ✅ اختيار تاريخ السداد أصبح عبر تقويم شهري تفاعلي (مع إمكانية التنقل بين الأشهر واختيار "اليوم" مباشرة).
- ✅ إصلاح مشكلة تجمّد البوت عند الضغط على "❌ إلغاء الأمر" أثناء تسجيل عملية تحصيل أو أي إدخال نصي آخر.
- ✅ عند تسجيل المندوب لعملية سداد، تُرسل إشعار تلقائي لجميع حسابات المدير بتفاصيل العملية.
- ✅ عند إرسال رسالة (لجميع المندوبين أو لمندوب محدد)، يمكن الآن الاختيار بين كتابة رسالة مخصصة أو استخدام رسالة جاهزة "⚠️ التحصيل ضعيف".
- ✅ شعار الشركة أصبح يظهر أعلى يمين كل صفحة PDF، وأسفل كل صفحة نص صغير "Powered by Anas Bu Grain".

## أول تشغيل
عند إرسال `/start` لأول مرة (ولا يوجد أي حساب مدير في قاعدة البيانات بعد)، سيطلب منك البوت
مباشرة إنشاء حساب المدير الأول (الاسم، اسم المستخدم، الرقم السري). بعدها يمكن للمدير:
- إضافة المندوبين والمساعدين من داخل البوت.
- تحديد صلاحيات كل مساعد.
- تحديد الأهداف الشهرية، متابعة التحصيلات، استخراج التقارير، وإرسال الرسائل.

## النشر على Railway (نفس أسلوب مشاريعك السابقة)
1. أنشئ مستودع GitHub وارفع هذه الملفات إليه.
2. أنشئ مشروع جديد على Railway مرتبط بالمستودع.
3. أضف متغيرات البيئة:
   - `BOT_TOKEN` = التوكن الخاص بالبوت (Alhayapharma_bot)
   - `DB_PATH` = `/data/alhaya.db` (بعد إنشاء Volume مثبّت على `/data`، لتبقى البيانات محفوظة عند كل تحديث للكود — تماماً كما فعلنا في بوت "المكتب")
4. أنشئ Volume في Railway وثبّته على المسار `/data`.
5. تأكد من رفع ملف الخط العربي داخل مجلد `fonts/` قبل النشر.
6. شغّل الخدمة — الأمر الافتراضي هو `python bot.py`.

## ملاحظات
- كلمات المرور مُخزّنة بصيغة hash (SHA-256 + salt) وليست نصاً صريحاً.
- كل عملية سداد مرتبطة بالمندوب الذي سجّلها ولا يمكن التعديل عليها من قبل المندوب نفسه بعد الحفظ.
- انتهاء الجلسة تلقائياً بعد 30 دقيقة من عدم النشاط (قابل للتعديل عبر `SESSION_TIMEOUT_MINUTES` في أعلى الملف).
- هذا إصدار أول (v1) قابل للتوسع مستقبلاً دون الحاجة لإعادة بناء قاعدة البيانات، تماشياً مع طلبك.
